# Portfolio — Ariel Yvane Brou

Portfolio personnel moderne, responsive et compatible avec GitHub Pages.

## Structure
- `index.html` : contenu du portfolio
- `style.css` : design, animations et responsive
- `script.js` : effets interactifs
- `assets/portrait.png` : photo de profil

## Mise en ligne sur GitHub Pages
1. Créer un dépôt GitHub.
2. Importer tous les fichiers du dossier.
3. Aller dans **Settings → Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner `main` et `/ (root)`.
6. Enregistrer.

Le site ne nécessite ni PHP ni MySQL : il est entièrement statique.

## Avant publication
Dans `index.html`, remplace `contact@example.com` par ton adresse e-mail réelle.
